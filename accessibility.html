Accessibility

McFarlands aims to provide an accessible website and mobile shopping experience.

Last updated November 24, 2026

Website accessibility

Our website includes semantic headings, labeled navigation, visible focus states, keyboard-accessible menus, descriptive text for product imagery, and reduced-motion support.

iPhone accessibility

The iPhone app is built using SwiftUI and is intended to work with supported iOS accessibility features. We continue to check VoiceOver labels, readable type, touch targets, contrast, and purchasing flows.

Report a barrier

If something is inaccessible, contact ios.dev.rasimmons@icloud.com. Describe the feature, device, and assistive technology involved so we can investigate.
